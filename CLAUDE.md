# Project notes

- **UI work:** read [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md) first. It is the visual and interaction standard (Airbnb-like: white, greys, one berry accent, Figtree, photo-led, motion on every state change). Never use native `<select>` or `type="date"`; use `@/components/ui/select` and `@/components/ui/date-picker`.
- **Ongoing redesign:** [docs/plans/ui-redesign.md](docs/plans/ui-redesign.md) records what was built, what still needs checking with a database, open decisions and gotchas.
- **Product and architecture:** see `docs/` (ARCHITECTURE, BUSINESS-FLOW, DATABASE, IMPLEMENTATION_PLAN).
